---Flabby-Fish-Pygame

A simple Flappy Bird clone with an ocean theme, built using Python and Pygame. 

---IMPORTANT: ASSETS REQUIRED

To keep the repository lightweight and fast to clone, the heavy audio and graphics files (assets/ folder) are **not** included directly in the source code. 

---How to set up and run the game:

1. Download or clone the source code files (main.py, etc.) from this main page.
2. Look at the right sidebar of this GitHub page and click on **Releases**.
3. Download the assets.zip file from the latest release (e.g., v0.1.0).
4. Extract the zip file and place the yellow assets folder directly in the same directory as your main.py file.
5. Run main.py to start the game!
